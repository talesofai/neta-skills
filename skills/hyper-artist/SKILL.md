# Hyper Artist

`hyper-artist` is the art equivalent of `hyper-beat`:

```text
arbitrary user query → Agent intent understanding → explicit search queries
→ provider search → Agent selection/ordering → 3×3 moodboard image
```

The CLI is intentionally a **dumb, deterministic execution layer**. It does not contain an artist/style/era dictionary, does not infer intent, and does not translate Chinese or abstract concepts. Those are language-model tasks and should remain in the Agent layer.

## Responsibilities

### Agent responsibilities

1. Understand any user request: artist, style, period, subject, vibe, use case, object, reference, or a mixture.
2. Decide whether the information need is precise or divergent.
3. Translate the intent into one or more concrete English search expressions.
4. Choose providers based on coverage and licensing needs.
5. Inspect metadata and, when vision is available, inspect the returned images.
6. Select the final nine images and arrange them in semantic order.
7. Call `assemble` with the selected artwork JSON. The input order is preserved by default.
8. Present both the moodboard image and the text/JSON metadata containing image URLs, source pages, and licenses.

### CLI responsibilities

- Send literal query strings to provider APIs.
- Normalize provider responses into one artwork schema.
- Preserve the original `search_query` on every result.
- Deduplicate provider object IDs.
- Download images directly, then retry failed downloads through `MEDIA_FETCH_PROXY_URL`.
- Center-crop, resize, and compose images.
- Save a JPEG moodboard and a JSON sidecar.

## Provider set

| Provider | License/filter | Coverage | Use |
|---|---|---|---|
| `met` | Public Domain / CC0 open-access images | Global, ancient to modern, very large | Default historical and global source |
| `cleveland` | `cc0=1` | Global collection, strong Asian art | Open-access museum metadata and images |
| `europeana` | PDM, CC BY, CC BY-SA | Aggregated European cultural heritage (17k+ open-licensed images) | Supplemental European source; inspect license carefully |
| `openverse` | CC0, Public Domain Mark, CC BY, CC BY-SA | Broad open web index, useful for contemporary and geographically broad work | Supplemental source; inspect source/license carefully |

> ⚠️ **Artic (Art Institute of Chicago) is deactivated in this environment.** Its IIIF image CDN returns 403 from both sandbox IP and the Media Fetcher proxy. Search metadata is still served, but images cannot be downloaded. Do not include `artic` in `--providers`.

The first two providers need no API key. Europeana uses a shared `apidemo` key by default; set `EUROPEANA_API_KEY` env var to override. Openverse requires `OPENVERSE_API_KEY` env var. See [docs/openverse-registration.md](docs/openverse-registration.md) for registration.

## Literal search commands

```bash
# One query, one provider
python3 .agents/skills/hyper-artist/cli.py search \
  "Claude Monet water lilies" --provider cleveland --limit 12 --format json

# One query across providers
python3 .agents/skills/hyper-artist/cli.py multi \
  "French Impressionist garden" \
  --providers met,cleveland,europeana --limit 18 --format json

# Several queries generated by the Agent
python3 .agents/skills/hyper-artist/cli.py batch \
  --query "Claude Monet water lilies" \
  --query "French Impressionist garden pond" \
  --query "post-impressionist flowers reflected water" \
  --providers met,cleveland,openverse,europeana \
  --per-query 12 --limit 36 --format json
```

`batch` does not alter the queries. It searches each literal expression and interleaves results by query and provider. The returned `search_query` field makes the source strategy inspectable.

## Recommended Agent workflow

### Precise information need

Example user request: “找梵高和星空有关的九幅画，做成 1:1 moodboard。”

Generate explicit expressions such as:

```text
Vincent van Gogh starry night
Vincent van Gogh night sky
Van Gogh stars landscape
Post-Impressionism starry sky
```

Then:

```bash
python3 .agents/skills/hyper-artist/cli.py batch \
  --query "Vincent van Gogh starry night" \
  --query "Vincent van Gogh night sky" \
  --query "Van Gogh stars landscape" \
  --query "Post-Impressionism starry sky" \
  --limit 36 --format json > /tmp/hyper-artist-results.json
```

Review the results, put the preferred nine artwork objects first, optionally append several fallback candidates, and assemble:

```bash
python3 .agents/skills/hyper-artist/cli.py assemble \
  --input /tmp/hyper-artist-selected-and-fallbacks.json \
  --aspect 1:1 --layout input --format json
```

The compositor walks the candidate list in order and uses the first nine images it can download. This preserves the Agent's semantic order while surviving temporary CDN failures.

### Divergent information need

Example user request: “我想找一种潮湿、神秘、哥特但有浪漫感的视觉参考。”

Generate several independent search angles rather than one overloaded query:

```text
gothic nocturne chiaroscuro painting
romantic dark landscape
medieval cathedral candlelight
symbolist mysterious garden
Caravaggio dramatic shadow
```

Use `batch`, inspect the mixed result set, then select nine images that form a coherent visual progression. The model should decide whether the final order is by light, color, composition, historical progression, or another meaningful relation.

### Any other request

Decompose the request into search dimensions as appropriate:

- artist + subject
- artist + period
- style + subject
- culture + medium
- era + region + subject
- use-case constraints translated into visual attributes
- several broad neighboring concepts for divergent discovery

The CLI should receive the resulting English expressions, not the original unprocessed intent, unless the raw query itself is already a good search expression.

## Moodboard commands

`moodboard` is a convenience command for literal queries. It searches, takes the first page of results, downloads images, and saves a board:

```bash
python3 .agents/skills/hyper-artist/cli.py moodboard \
  --query "Claude Monet water lilies" \
  --query "French Impressionist pond" \
  --limit 9 --aspect 1:1 --layout input --format json
```

A positional query is also supported:

```bash
python3 .agents/skills/hyper-artist/cli.py moodboard "Hokusai wave ukiyo-e" --aspect 16:9
```

Use `--offset 9` for another page of results. A second moodboard is the visual equivalent of asking Hyper Beat for more tracks.

Supported aspect ratios:

- `1:1`: square board, square cells
- `16:9`: landscape board, landscape cells
- `9:16`: portrait board, portrait cells

The compositor center-crops each image to the selected cell ratio. It creates a fixed 3×3 canvas; missing images remain empty rather than silently changing the requested format.

## Semantic ordering

The compositor cannot understand image meaning. Use:

- `--layout input` for LM-selected semantic order. This is the default and recommended path.
- `--layout balanced` as an alias for preserving the supplied order.
- `--layout chronological` for deterministic date order.
- `--layout color` for a simple dominant-hue sort, not visual-semantic reasoning.
- `--layout random` only for exploration.

If the Agent has vision capability, it should select and order the nine objects itself, then use `assemble --layout input`. Do not ask the CLI to make a semantic claim it cannot support.

## Output schema

Search output:

```json
{
  "queries": ["Claude Monet water lilies", "French Impressionist pond"],
  "providers": ["met", "cleveland", "openverse"],
  "count": 24,
  "artworks": [
    {
      "id": "met-436418",
      "title": "Jerusalem from the Mount of Olives",
      "artist": "Charles-Théodore Frère",
      "date": "by 1880",
      "culture": "",
      "medium": "Oil on canvas",
      "classification": "Paintings",
      "image": "https://...",
      "thumbnail": "https://...",
      "url": "https://...",
      "provider": "met",
      "license": "CC0 / Public Domain",
      "credit": "The Met",
      "search_query": "Claude Monet water lilies"
    }
  ]
}
```

Moodboard output additionally contains:

```json
{
  "moodboard_path": "/workspace/outputs/hyper-artist/moodboard_....jpg",
  "metadata_path": "/workspace/outputs/hyper-artist/moodboard_....json",
  "aspect": "1:1",
  "layout": "input"
}
```

Always return or present:

1. The moodboard image path or public URL.
2. The nine selected artworks and direct image URLs.
3. Museum/source page URLs.
4. Exact license and attribution information.

## Legal and operational constraints

- Keep images on provider CDNs unless a moodboard must be rendered locally.
- Do not claim every Openverse item is public domain; preserve and display its exact license.
- For CC BY and CC BY-SA, include creator, source, and license attribution.
- Do not use a copyrighted image simply because a museum page exposes it. Prefer records with explicit open-access/public-domain status.
- Do not put tokens or provider credentials in queries, output, or files.
- If a provider or image CDN fails, retry image download through the Media Fetcher `/proxy?url=...&referer=...&ua=...` endpoint, then continue with other candidates if the upstream still rejects both egress paths.
- Artic (Art Institute of Chicago) is removed from active providers — its IIIF CDN is reliably blocked in this environment. Do not use `artic`.
- `outputs/hyper-artist/` is local working output. Publish a board through `/public/` only when a public URL is required, and never write to `/workspace/public/`.

## Architecture

```text
Agent / LM
  ├─ query understanding
  ├─ precise vs divergent decision
  ├─ English query generation
  ├─ visual inspection and nine-image selection
  └─ semantic ordering
       ↓ explicit query strings / selected artwork JSON
hyper-artist CLI
  ├─ museum adapters + optional Openverse adapter
  ├─ normalized metadata and license fields
  ├─ literal multi-query search
  ├─ direct download → Media Fetcher proxy fallback
  └─ crop + resize + 3×3 JPEG compositor
```
